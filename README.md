# COM2016 - Programming with Python

This repository contains coursework and supporting programming exercises for COM2016 - Programming with Python module at the University of Exeter. 

The work in this repository focuses on: 
- Problem decomposition and program design. 
- Core Python programming concepts. 
- Use of standard Python libraries. 
- Basic software engineering practices including testing and documentation. 

## Repository Structure

- coursework/
- exercises/ 
- workshops/ 
- readme/ 

## coursework/

This folder contains the main assessed project for this module. 


## Tools and environment

- Python 3.14.2
- Visual Studio Code
- Standard Python Libraries
- Git for control version

## Notes

This repository is primarily an academic workspace. Structure, readability and correctness are prioritised over optimisation or advanced techniques.
